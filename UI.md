## Menu

Button 1 Click: Back to `Main` screen
Button 3 Click: Open the `System Information` screen
Button 4 Click: Save the current settings to NVS

### System Information

Button 1 Click: Back to `Menu` screen

## Main

Button 1 Click: Opens the `Menu` screen
Button 2 Click: Show / Hide the ROIs when in thermal mode. Enable / Disable the flash when in RGB mode
Button 2 Long Press: Activates the `ROI configuration menu`
Button 3 Click: Switch to RGB / thermal mode
Button 4 Click: Save the current image to the currently active storage (Internal or SD)

### ROI configuration menu

Button 1 Click: Save and Back
Button 2 Click: Rotate through the available ROIs. Default when entering: ROI 1 (Spotmeter)
Button 3 Click: Switch between resizing and moving the selected ROI. Default when entering: Resize
Button 4 Click: Reset the selected ROI to his default values.
Button 4 Long Press: Reset all ROIs to their default values

The selected ROI is blinking and the position / size can be changed by using the joystick.
