== Overview

The Device Manager is the central hardware abstraction layer for the PyroVision firmware.
It initializes and manages all peripheral I2C and SPI hardware, exposes a unified application
API, and handles event posting for hardware state changes.  The following IC drivers are
integrated and managed through this module:

[cols="1,2,1,1", options="header"]
|===
| Driver | Device | Interface | I2C Address

| TMP117
| High-accuracy temperature sensor
| I2C (main bus)
| 0x48

| RV8263-C8
| Real-time clock (RTC)
| I2C (main bus)
| 0x51

| PCA9633DP1
| 4-channel PWM LED driver
| I2C (main bus)
| 0x62

| MAX17048
| Li-Ion/LiPo fuel gauge
| I2C (main bus)
| 0x36

| PCAL6416AHF (mainboard)
| 16-bit I/O port expander -- system signals
| I2C (main bus)
| 0x20

| PCAL6416AHF (displayboard)
| 16-bit I/O port expander -- joystick + buttons
| I2C (main bus)
| 0x21

| VL53L1X
| Time-of-Flight distance sensor
| I2C (main bus)
| 0x29

| GT911
| Capacitive touch controller
| I2C (touch bus, I2C_NUM_1)
| configured by driver
|===

=== Key Features

* *Unified hardware init*: Single `DevicesManager_Init()` call brings up all peripherals.
* *isInitialized guard*: Every low-level driver instance exposes an `isInitialized` flag.
  All non-Init API calls return `ESP_ERR_INVALID_STATE` immediately when the instance has not
  been successfully initialized.
* *Event system*: Hardware state changes (battery alert, charging state, SD-card detect,
  port expander interrupts, displayboard inputs) are communicated via the ESP event system
  using the `DEVICES_EVENTS` base.
* *Dual port expander*: Two PCAL6416AHF instances share the main I2C bus.  The mainboard
  instance handles system-level signals.  The displayboard instance is optional and handles
  joystick and button inputs.
* *Thread-safe bus sharing*: All I2C transactions use individual dev-handles managed by the
  ESP-IDF I2C master driver.

=== Hardware Buses

==== Main I2C Bus (I2C_NUM_0)

* *SDA / SCL*: Configured via `CONFIG_DEVICES_I2C_SDA` / `CONFIG_DEVICES_I2C_SCL`
* *Clock speed*: 400 kHz (Fast-mode)
* *Glitch filter*: 7 cycles

All seven I2C sensors listed in the overview table share this bus via individual
`i2c_master_dev_handle_t` handles.

==== Touch I2C Bus (I2C_NUM_1)

* Dedicated bus for the GT911 capacitive touch controller.
* Prevents interference between high-speed touch polling and sensor communication.
* Handle returned by `DevicesManager_GetTouchI2CBusHandle()`.

==== SPI Bus (SPI2_HOST)

* *MOSI / MISO / SCLK*: Configured via `CONFIG_SPI_MOSI` / `CONFIG_SPI_MISO` / `CONFIG_SPI_SCLK`
* *Max transfer size*: `CONFIG_SPI_TRANSFER_SIZE` bytes
* *DMA*: Auto-selected channel
* *Connected devices*: ILI9341 LCD display, optional SD card

==== ADC

* Used exclusively for battery voltage measurement via an external resistor divider.
* Measurement enable / disable is controlled through the mainboard PCAL6416AHF.

=== TMP117 High-Accuracy Temperature Sensor

The TMP117 is a high-precision digital temperature sensor with +/-0.1 degC accuracy (typ.)
and a 0.0078125 degC resolution (7.8125 m degC per LSB).  It communicates over I2C at
address 0x48.

==== Device Instance

    bool isInitialized;                 /**< True after successful initialization. */
    i2c_master_dev_handle_t Handle;     /**< I2C device handle. */
} TMP117_Dev_t;
----

    TMP117_MODE_ONE_SHOT    = 0x03,     /**< One-shot conversion mode. */

=== PCA9633DP1 4-Channel PWM LED Driver

The PCA9633DP1 is a 4-channel I2C LED driver with 8-bit PWM per channel.  It is used to
drive the RGB status LED and a flash LED through NPN transistors.  The driver operates in
totem-pole output mode (`OUTDRV = 1`) with polarity inversion enabled (`INVRT = 1`).

NOTE: The output polarity inversion (`INVRT = 1`) combined with the NPN transistor topology
means that writing a high PWM value drives the LED *on*.  A duty cycle of 0 turns the LED
fully off; 255 drives it at full brightness.

==== Device Instance

[source,cpp]

    i2c_master_dev_handle_t Handle;         /**< I2C device handle. */
} PCA9633DP1_Dev_t;
----

==== Types

    PCA9633_LED1 = 1,                       /**< LED channel 1. */
    PCA9633_LED2 = 2,                       /**< LED channel 2. */
    PCA9633_LED3 = 3,                       /**< LED channel 3. */
} PCA9633_LED_t;

typedef enum {
    PCA9633_LED_OFF      = 0,               /**< LED driver off (default at power-up). */
    PCA9633_LED_FULLY_ON = 1,               /**< LED driver fully on (not PWM-controlled). */
    PCA9633_LED_PWM      = 2,               /**< LED driver individual PWM control. */
} PCA9633_LED_State_t;
----

=== MAX17048 Li-Ion / LiPo Fuel Gauge

The MAX17048 is a compact fuel-gauge IC that uses the ModelGauge algorithm to estimate
battery state of charge (SOC) without requiring a sense resistor.  It is accessible at

=== PCAL6416AHF 16-Bit I2C Port Expander

The PCAL6416AHF is a 16-bit I2C GPIO expander with built-in interrupt masking, input
latching, and programmable pull resistors.  Two instances are used:

[cols="2,1,3", options="header"]
|===
| Instance | I2C Address | Function

| Mainboard
| 0x20
| System signals: battery alert, charging state, Lepton power/reset, camera power/reset,
  backlight control, SD-card detect, RTC/temp/range interrupt pins

| Displayboard (optional)
| 0x21
| User input: 5-way joystick (P0.3--P0.7) and four push-buttons (P1.0--P1.3)
|===

NOTE: The displayboard expander is optional.  If the displayboard is not connected,
`DevicesManager_GetDisplayboardInputs()` returns `ESP_ERR_NOT_SUPPORTED`.

* `ESP_OK` -- Success
* `ESP_ERR_INVALID_ARG` -- Any pointer is NULL
* `ESP_FAIL` -- I2C bus registration or register configuration failed

Removes the device from the I2C bus.

===== PCAL6416AHF_WritePin()

[source,cpp]

===== PCAL6416AHF_ReadInputs()

[source,cpp]
----
esp_err_t PCAL6416AHF_ReadInputs(PCAL6416AHF_Dev_t *p_Device,
                                  uint8_t *p_Input0, uint8_t *p_Input1);
----

Reads both INPUT registers in a single I2C burst transfer (writes the INPUT0 register
address once, then reads two bytes in the same transaction).  This is the preferred
method for polling all input pins without saturating the bus.

NOTE: Avoid interleaving `PCAL6416AHF_ReadInputs()` and `PCAL6416AHF_ReadIntStatus()` on
the same device instance, as both update the chip's change-detection reference.

===== PCAL6416AHF_ReadIntStatus()

[source,cpp]
----
esp_err_t PCAL6416AHF_ReadIntStatus(PCAL6416AHF_Dev_t *p_Device,
                                    uint8_t *p_Status0, uint8_t *p_Status1,
                                    uint8_t *p_Input0, uint8_t *p_Input1);
----

Reads and clears both INT_STATUS registers (releasing INT#) and then reads both INPUT
registers to refresh the change-detection snapshot and release any active input latches.

NOTE: For latched input pins, the INPUT values returned reflect the captured state at
interrupt time, not a later live read.

=== VL53L1X Time-of-Flight Distance Sensor

The VL53L1CXV0FY1 is an ST SPAD-based Time-of-Flight ranging sensor supporting two
distance modes: Short (up to ~1.3 m) and Long (up to ~4 m).  It communicates over I2C
at address 0x29.

==== Device Instance

    VL53L1X_DistanceMode_t DistanceMode;    /**< Current distance mode. */
    uint16_t OscCalibrateVal;               /**< Oscillator calibration value (read at init). */
    bool Calibrated;                        /**< True after first GetResult() calibration. */
    uint8_t SavedVhvInit;                   /**< Saved VHV_CONFIG__INIT. */
    uint8_t SavedVhvTimeout;                /**< Saved VHV timeout. */
} VL53L1X_Dev_t;

== Devices Manager API

The Devices Manager is the application-level interface.  It owns all device driver
instances, orchestrates initialization, and exposes higher-level functions.

=== Events (DEVICES_EVENTS)

Events are posted on the default event loop using the `DEVICES_EVENTS` event base.

[cols="2,1,3", options="header"]

| Event ID | Data type | Description

| `DEVICES_EVENT_BATTERY_ALERT`
| `bool`

| `DEVICES_EVENT_BATTERY_CHARGING`
| `bool`
| Battery charging state changed (true = charging; P0.1)

| `DEVICES_EVENT_RTC_INTERRUPT`
| --
| RTC interrupt asserted (active-low; P0.5)

| `DEVICES_EVENT_TEMP_INTERRUPT`
| --
| Temperature sensor interrupt asserted (active-low; P0.7)

| `DEVICES_EVENT_RANGE_INTERRUPT`
| --
| Range sensor interrupt asserted (active-low; P1.0)

| `DEVICES_EVENT_SD_DETECT`
| `bool`
| SD-card detection state changed (true = card inserted; P1.4, polarity-inverted)

| `DEVICES_EVENT_INPUT_CHANGED`

|===

== Usage

=== Initialization Workflow

[source,cpp]
----
#include "devicesManager.h"
#include "timeManager.h"
#include "settingsManager.h"

void app_main(void)
{
    /* 1. NVS */
    esp_err_t Error = nvs_flash_init();
    if (Error == ESP_ERR_NVS_NO_FREE_PAGES || Error == ESP_ERR_NVS_NEW_VERSION_FOUND) {
        ESP_ERROR_CHECK(nvs_flash_erase());
        Error = nvs_flash_init();
    }
    ESP_ERROR_CHECK(Error);

    /* 2. Event loop */
    ESP_ERROR_CHECK(esp_event_loop_create_default());

    /* 3. Settings Manager */
    ESP_ERROR_CHECK(SettingsManager_Init());

    /* 4. Device Manager -- MUST come before Time Manager */
    ESP_ERROR_CHECK(DevicesManager_Init());

    /* 5. Time Manager -- requires RTC handle */
    RV8263C8_Dev_t RTCHandle;
    ESP_ERROR_CHECK(DevicesManager_GetRTCHandle(&RTCHandle));
    ESP_ERROR_CHECK(TimeManager_Init(&RTCHandle));
}
----

=== Handling Displayboard Inputs via Events

[source,cpp]
----
static void on_devices_event(void *p_Arg, esp_event_base_t Base, int32_t ID, void *p_Data)
{
    if (Base == DEVICES_EVENTS && ID == DEVICES_EVENT_INPUT_CHANGED) {
        const Devices_InputState_t *p_State =
            static_cast<const Devices_InputState_t *>(p_Data);

        if (p_State->JoyUp) {
            ESP_LOGI(TAG, "Joystick UP");
        }

        if (p_State->Button1) {
            ESP_LOGI(TAG, "Button 1 pressed");
        }
    }
}

/* Register handler */
esp_event_handler_register(DEVICES_EVENTS, DEVICES_EVENT_INPUT_CHANGED,
                           on_devices_event, NULL);
